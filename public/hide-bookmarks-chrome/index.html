How to hide bookmarks in Chrome on a shared computer

Last updated: 17 November 2026

You share the PC, or someone else uses your Chrome profile, and there are links in your bookmarks you would rather not explain: a job search, a medical page, a gift, a client's staging URL. The bookmarks bar can be hidden with one keystroke — but hiding the bar is not hiding the bookmarks. This page goes through what Chrome actually protects, what it does not, and how to put a password in front of the list with PrivateLinkSaver.

What Chrome can and cannot hide

  • Hide the bar, not the bookmarks. Ctrl+Shift+B (or the Show bookmarks bar item in the menu) removes the bar from view. Every bookmark is still in the bookmark manager at Ctrl+Shift+O, in the folder menus, and in the address bar's suggestions. Anyone who knows those two shortcuts has seen your list.
  • A second profile is not a locked profile. It keeps work and personal bookmarks apart, and it stops someone casually browsing your folders. It has no password: the profile avatar sits in the toolbar and anyone can switch to it. Chrome's profile lock protects the profile against another operating system account, not against someone using yours.
  • Guest and incognito keep nothing. That is the point of them: close the window and the bookmark, the history and the cookies are gone. Useful for a link you need once, useless for one you need tomorrow.
  • Sync spreads them. Turning on sync copies your bookmarks to every device signed into the Google account. Convenient, and the opposite of keeping a subset private.

The short version: Chrome has no password on bookmarks, no private folder, and no way to mark a single bookmark as hidden.

The options, from lightest to strongest

1. A Guest window, for one link

Chrome menu → Open Guest window. Nothing is written to the profile while you browse, so there is nothing to hide afterwards. It is the fastest option and it protects nothing you want to keep.

2. A separate Chrome profile

Quick to create, and it separates the two sets of bookmarks and history completely. It fails the moment the other person clicks the avatar — there is no password on it.

3. A separate operating system account

The strongest separation Chrome itself can offer, because the other person cannot read your browser profile files at all. It is also the heaviest: it splits everything, not just one folder of links.

4. A bookmark vault extension

The list lives in the extension's own encrypted storage behind a master password, so opening it takes a deliberate step. It is the only option here that locks a subset of links instead of the whole profile.

What a vault does differently

A bookmark vault keeps its own list. Chrome's bookmark manager never sees those links: they are not in the bookmarks file, not in the bar, and not in the address bar's suggestions. PrivateLinkSaver works that way — a master password locks the panel, folders with colours and tags organise the links, Ctrl+Shift+S saves the current page and Ctrl+Shift+F searches the list. The interface is available in English, Swedish, Turkish, Spanish and French, and syncing to other devices is optional.

One detail worth knowing before you trust it: local storage is not encrypted by default. Turn on Encrypt local data in Settings — that is what applies AES-256-GCM with a key derived from your master password through PBKDF2-SHA256. Without it, the master password is a lock on the interface, not encryption at rest.

Setting it up

  1. Install PrivateLinkSaver from the Chrome Web Store and open it from the toolbar.
  2. Set a master password you have not used elsewhere. The encryption key is derived from it, so there is no server-side reset to fall back on — pick one you will remember.
  3. Open Settings and turn on Encrypt local data. Do this before you save anything worth protecting.
  4. Move the private links across. Open each page, press Ctrl+Shift+S, then delete the bookmark from Chrome. Deleting it is the step people skip — a link that is still in Chrome's bookmarks is still readable.
  5. Check your work. Press Ctrl+Shift+B and Ctrl+Shift+O: if the links no longer appear in the bar or the manager, they are out of Chrome's list.

What this protects against — and what it does not

Protected

  • Someone opening your browser while you are away from the desk.
  • A shared family PC where the other person knows about the bookmark manager.
  • A link on screen in the bar, in a suggestion list or in a screenshot.

Not protected

  • Someone with your operating system account and a keylogger.
  • The vault's storage while it is unlocked and open on screen.
  • Anyone you have given the master password to.
  • Chrome's history and address bar autocomplete, which are stored separately and are not cleaned up by saving a link in a vault.

If it is only one link

Use an incognito window: Ctrl+Shift+N on Windows and Linux, Cmd+Shift+N on a Mac. Nothing is saved, so there is nothing to find later — which is exactly the trade you are making.

Questions people ask

Can I password-protect a single Chrome bookmarks folder?

No. Chrome has no per-folder or per-bookmark password. The whole profile can be tied to your operating system account, but anyone using that account sees every bookmark in it.

Does hiding the bookmarks bar hide the bookmarks?

No. It only removes the bar. The bookmark manager (Ctrl+Shift+O), the folder menus and the address bar suggestions still show everything.

Is incognito the same as a private bookmark folder?

No. Incognito keeps nothing, so a bookmark saved there disappears when the window closes. A private folder would have to keep the link — Chrome has no such feature.

Where are the saved links stored?

Locally in the browser, in the extension's own storage behind the master password. Cloud sync is optional, and when it is on, the data is encrypted on the device before it is uploaded.

Does it work in Edge, Brave and Opera?

Yes. It is a Manifest V3 extension published in the Chrome Web Store, so Chromium browsers such as Edge, Brave, Opera and Vivaldi can install it. Firefox is a different extension platform and is not supported by this build.

What happens if I forget the master password?

The key that decrypts your links is derived from that password. There is no server holding a copy of it, so treat the password as the only way into the list.
