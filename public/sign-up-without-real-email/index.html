Sign up for a site without giving it your real email address

Last updated: 17 November 2026

You want to try a service, or test a sign-up flow of your own, and the form asks for an address you would rather not hand over. A temporary inbox solves part of that. The rest — getting the confirmation code back into the page and keeping the login afterwards — is where most people give up and type their real address. This page covers both routes, with and without AutoAccountMaker.

What “without your real email” actually requires

It is three separate jobs, and only the first one is easy:

  • An address that can receive mail. A made-up address is useless, because the site sends a code or a confirmation link and something has to be able to open it.
  • A form filled in consistently. Name, address and password have to match, and the boxes the site requires have to be ticked, or the form comes back with an error and often clears itself.
  • A way to get the code back into the page. Verification mail arrives in another tab, the code expires in minutes, and some sites only send a link that has to be opened in the same browser.

A temp-mail website gives you the first. The second and third are yours to do by hand, and they are the slow part.

Doing it by hand

  1. Open a temp-mail service in a second tab and copy the address. Leave the tab open: the inbox lives in that tab, and some services expire an address after a few minutes of disuse. Note the address somewhere before you start typing it into a form.
  2. Fill the form. Use a password you have not used anywhere else — the address is disposable, but the password is what protects the account while it exists.
  3. Submit, then switch tabs and wait. Verification codes usually expire within 10–15 minutes. If the message contains a link instead, open it in the same browser profile you registered in.
  4. Write down the address, the password and the site. When the inbox disappears you cannot receive a password reset, so the login is all you will have.

Where the manual route breaks

  • The tab is the account. Close it, or let the address expire early, and the confirmation mail is gone with no way to ask for another one.
  • Custom forms. Native dropdowns are easy. Hand-built listboxes, fields inside web components, and six-box code inputs are not, and a wrong guess clears the form you just filled.
  • Timing. Some sites send the mail half a minute late, some open a modal over the form, and some log you out of the registration flow while you are in the other tab.
  • Bookkeeping. Three sign-ups later, nobody remembers which address belongs to which site.

One click instead of four tabs

AutoAccountMaker does the whole run in one go. It creates a temporary address and a password, fills the fields, ticks the required boxes, submits the form, waits for the verification mail, enters the code (or opens the link), and logs in. The account is saved to a vault, so the next visit only needs Log in.

Filling the form

Names, email, confirmation, password, country, gender and date of birth. Ordinary inputs, native selects, dropdowns and listboxes built out of divs, and code fields. Fields inside a shadow root — sites built from web components such as <w-textfield> — are reached too, which plain HTML injection cannot do.

Reading the code

It waits for the message, reads the code and enters it, whether the page uses one field or six small boxes. If the site sends a link instead, the link is opened and the flow continues from there.

The vault

Accounts are stored locally in the browser, capped at 10, 50 or 199. Export to CSV or PDF, or to an encrypted .enc backup that needs a master password on export and on import. CSV and PDF leave passwords out unless you tick Include passwords, and neither of those files is encrypted.

What it will not do

  • Solve CAPTCHAs. It ticks the checkbox and lets the site do its own check. There is no image or proof-of-work solver, so a site that demands more than a click stops the run.
  • Create phone numbers. It is email only. A site that requires an SMS code cannot be completed.
  • Guarantee the account. “Verified” means the site accepted the code it was sent. A site that rejects the account later is outside the extension's control.
  • Work on every form. Fields are found with heuristics. Unusual flows, heavy bot protection or a site's own login logic can refuse the registration or fill it only partly — and that does not change with a bigger version number.
  • Ignore the provider. If mail.tm or the RapidAPI provider rate-limits you, or a message never arrives, the run fails. The free tier also allows one automated sign-up every three hours; Pro removes the wait.

Is a temporary address allowed?

Sometimes. What matters is the site's terms, not the tool. Plenty of services accept disposable addresses, and plenty forbid them outright or block known temp-mail domains, in which case the sign-up simply fails with a generic error. The terms take a minute to read.

Two things worth avoiding: using it to get around a limit you already agreed to — trial abuse, vote or referral manipulation — and using it where the account has to stay reachable. Banking, work and anything you would need support for need an address you actually own.

The extension is meant for testing your own sign-up flow and for trying a service without your personal address. It is not a tool for creating accounts in bulk on someone else's site.

Questions people ask

Will I lose the account when the temporary inbox expires?

You lose the ability to receive password resets and any later mail sent to that address. The account itself stays on the site for as long as the site keeps it, but treat the saved password as the only way in.

Which email providers can it use?

mail.tm by default: free, no key, works immediately. A RapidAPI key for temp-mail.org is optional and goes under Advanced in the settings. Both providers apply their own limits on how fast addresses can be created, and those limits are theirs, not the extension's.

Does it create phone numbers for SMS verification?

No. It creates email addresses only, so a site that insists on a phone number cannot be completed with it.

What happens on a site with a CAPTCHA?

The checkbox gets ticked and the site runs its own check. If it asks for an image puzzle or a proof-of-work challenge, the run stops there — there is no solver.

Is the free version enough to try it?

Yes, with one automated sign-up every three hours. Pro is a lifetime licence for one browser and removes the wait; it does not change what the extension is able to fill.

Where are the created accounts stored?

Locally in the browser, in the extension's vault. CSV and PDF exports leave passwords out unless you include them, and neither file is encrypted — use the .enc backup when the file has to travel.
