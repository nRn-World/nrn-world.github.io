No download button? How to save a video from a page in Chrome

Last updated: 17 November 2026

You are watching a video in Chrome and there is no download button anywhere — not on the player, not in the right-click menu, not in the page. That is usually not an accident: most modern players never publish a file link at all. This page explains why the button is missing, how to find the video the tab is actually loading, and how to save it with FlashVideoDownloader.

Why the download button is often missing

There are four common reasons, and they need different handling:

  • The player streams instead of linking. The page hands a file to a <video> element and never prints the address. The file is right there in the network traffic, but nothing on the page lets you click it.
  • The video is HLS (M3U8). Instead of one MP4, the player requests a playlist and then hundreds of short segments. There is no single file URL to right-click, which is why “save video as” often gives you a useless text file.
  • The player builds the stream in JavaScript. Some players use a blob: address through Media Source Extensions. That address only exists inside the page, so copying it into a new tab or a download manager does nothing.
  • The video is DRM-protected. Netflix, Disney+, Prime Video and similar services encrypt the stream and decrypt it inside the browser. There is no usable file to find, and an extension that claims otherwise is either misreporting or breaking the law.

Find the video the tab is already loading

The trick is not to search the page for a link, but to look at what the tab has already requested. That is exactly what FlashVideoDownloader does: it reads the media the active tab is loading and lists it in the toolbar popup.

  1. Start the video and let it play for a few seconds. Many players load nothing at all until you press play, so the extension has nothing to list before that.
  2. Click the FlashVideoDownloader icon. The popup shows the media this tab has requested: direct MP4 and WEBM files and M3U8 playlists, with the file size where the server reports one.
  3. Pick the entry you want and preview it. Previewing first avoids saving a trailer, an advert or a silent audio track by mistake. Downloads can be paused and cancelled.
  4. Save it. The file goes to your normal Downloads folder. Your history stays in the extension on your own machine — there is no account and no cloud library.

What it can and cannot do

What it does

  • Detects open videos in the active tab: MP4, WEBM and M3U8 playlists.
  • Preview, pause and cancel downloads, with a local history of what you saved.
  • Runs in Chrome, Brave, Edge, Opera and Vivaldi — all Chromium browsers.
  • Keeps everything on your device: no account, no cloud, no tracking.

What it does not do

  • It does not bypass DRM. Encrypted streams stay encrypted.
  • It does not download YouTube video, which the Chrome Web Store does not allow.
  • It does not fetch segments behind a login the browser cannot reach itself.
  • It does not turn a blob-only player into a file when no plain media URL exists.

If nothing is detected

A quick checklist before you blame the extension:

  • Press play and wait until the video actually starts. An idle player loads nothing.
  • Reload the page once and open the popup again — some players request media late.
  • Check whether the player uses DRM. If it does, no downloader will produce a playable file.
  • If the page shows an M3U8 entry instead of an MP4, that is the stream itself: the playlist is the video in its segmented form, not a broken download.

Only save videos you have the right to keep. Downloading someone else's broadcast or a subscription stream is usually a breach of that service's terms, and in many countries also of copyright law.

Questions people ask

Is there a hidden download button on the page?

Almost never. If the player is HTML5, the page holds a file address in its source, but that is not the same as a button. Reading the media the tab requested is the practical way to get it.

Why does it show an M3U8 file instead of an MP4?

Because the site streams with HLS. The M3U8 file is the playlist that points at the video segments, so what the tab loads is a playlist rather than one finished MP4.

Does it work in Edge, Brave and Opera?

Yes. Those browsers are built on Chromium and can install extensions from the Chrome Web Store. Firefox is not supported.

Is it free?

The extension is free to install and use, with an optional Pro licence through Ko-fi for people who want to support development. There is no account and no subscription to try it.

Does it work on Netflix, Disney+ or Prime Video?

No. Those services use DRM, and the extension explicitly does not bypass it. That is a limit of the format, not a bug to wait for.
