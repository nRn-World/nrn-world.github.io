How to put a sticky note on a web page — and still find it tomorrow

Last updated: 17 November 2026

You are reading something long: a contract, a spec, a product page you are comparing. You want to leave yourself a note on it — ask about this line, this price changed, come back to this paragraph. A bookmark is a link with a title, so it cannot hold that thought in the right place. This page goes through what actually works, and where each option breaks.

Three things people try first

Put it in the bookmark title

The bookmarks bar shows about a dozen characters before it truncates, and the rest ends up in a menu you never open. Worse, it mixes remarks into a list you use for navigation, so the note is now part of your filing system instead of the page.

Print the page to PDF and annotate that

Fine for a document you intend to keep. It falls apart for a page that changes, and the annotation lives in the PDF — not on the page you will actually revisit next week.

Keep a note in a notes app with the URL pasted in

The note survives; the context does not. You come back with a URL and one sentence, then re-read four thousand words looking for the paragraph the sentence was about.

What a note on a page needs

  • A place. The note should sit next to the thing it is about, so finding the note means finding the passage — not searching the page again.
  • Persistence. It has to survive a reload, a browser restart and a week of not visiting the page.
  • A way back. One list of every note, with a link to the page each note belongs to.
  • No interference. The note must not break the page's own clicks, keyboard shortcuts or scrolling.

Pinning a note with NotePin

NotePin adds a layer on top of the page instead of changing the page itself. On any site, hold the right mouse button for about a second — a normal right-click still opens the usual context menu, so the page keeps working — and choose Add Sticky Note.

  1. Hold right-click for a second on the page and pick Add Sticky Note. The note appears where you are pointing.
  2. Type. Every keystroke is saved as you type, so there is no save button to forget and no draft to lose.
  3. Move it, resize it, minimise it. Drag the top handlebar to move, the bottom-right corner to resize, and click a note to bring it to the front. The position is kept with the note.
  4. Come back later. Open the same page and the note is there, in the same spot, with the text you left.
  5. Find it again from the toolbar icon. Saved Notes lists every note with search, custom categories and a Go to page button that takes you back to the source.

What it keeps, and where

Notes live in the browser's own extension storage. There is no account, no server, no analytics and no telemetry — the extension makes no network calls of its own. Export takes the whole set to a JSON file, and import restores it, which is also how you move notes to a machine you did not sync. The interface is in English, Swedish, Spanish and French, and there is a Firefox build next to the Chrome one.

Chrome Sync is opt-in for anyone who wants notes on more than one computer, with one caveat from the release notes: sync has an 8 KB limit per item, which is why notes were moved to local storage in v1.0.8. If you write long notes, keep them local and use the JSON export as your backup.

Where this approach breaks

  • The note belongs to the URL. It is tied to the exact address it was created on, so a page that puts a session ID or a changing hash in the address may not show the note the next time you arrive. Logged-in dashboards and single-page apps are the usual culprits.
  • The note is not glued to the paragraph. It is saved at a position on that page. When a site redesigns, the text moves and the note stays where you left it — still there, just next to the wrong thing.
  • It is private by design, so it is not a review tool. Nobody else sees the note. For feedback to a colleague or a client you need a shared annotation service, not this.
  • It is not a highlighter. There is no text selection, no highlighting and no saved copy of what the page said — the note is a floating card next to the text.

Questions people ask

Do the notes sync between computers?

Only if you turn on Chrome Sync. The default is local storage on the machine where the note was written, and the JSON export is the portable copy.

What happens when a website changes its address?

The note is tied to the URL it was created on, so a new address is a different page as far as the extension is concerned. The old note stays in Saved Notes with the old address, so you can still read it and recreate it on the new one.

Does it work in Firefox and Edge?

There is a Firefox build on addons.mozilla.org alongside the Chrome Web Store listing. Edge, Brave and other Chromium browsers install the Chrome build.

Can I back up my notes?

Yes. The popup has a one-click JSON export and import, so the notes are portable and not locked to one browser profile.

Is it free?

Yes — no account, no ads, no paid tier. Development is supported through donations, and the source is on GitHub under CC BY-NC 4.0.

Will the notes show up on pages I open in a private window?

The note is stored against the page's address, so it is not tied to a normal or private session. What decides it is the URL: if the private window opens the same address, the note is there. If the site hands out a different address per visit, it is not.
